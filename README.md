# The Vent Alien

This is a 3d printed version of the singing alien from Spaceballs that peeks out of a broken vent, dances, and sings a song.

**[Watch the demo video]()**

If you want to recreate this project, there are some files not included in the repo because I didn't want to risk copyright infringement. These files are the 3d model of the alien itself, which I found on Thingiverse, and the audio of the song it sings, which you could use like any song for.
